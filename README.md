## Menjalankan Web Ini Secara Lokal

Website portofolio ini dibangun dengan HTML5 murni dan Tailwind CSS:

1. Clone repositori:
   ```bash
   git clone https://github.com/Biw-id/portfolio-web.git
   cd portfolio-web
   ```
2. Buka file `index.html` langsung di browser Anda atau gunakan ekstensi VS Code Live Server / static server apa pun (`npx serve .` atau `python -m http.server 3000`).
